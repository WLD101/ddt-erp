# WhatsQuery ERP: Hostinger VPS Deployment Guide

This guide provides step-by-step instructions for deploying WhatsQuery ERP on a clean Ubuntu 22.04/24.04 VPS.

---

## 1. System Preparation

Update packages and install dependencies:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git build-essential nginx
```

Install Node.js (Version 20+):
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v # Verify version
```

Install PostgreSQL:
```bash
sudo apt install -y postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

---

## 2. Database Setup

Login to Postgres and create the database/user:
```bash
sudo -i -u postgres
psql

# Inside psql:
CREATE DATABASE whatsquery_db;
CREATE USER wq_admin WITH PASSWORD 'SET_YOUR_DB_PASSWORD_HERE';
GRANT ALL PRIVILEGES ON DATABASE whatsquery_db TO wq_admin;
\q
exit
```

---

## 3. Application Deployment

Clone the repository (or upload via SFTP):
```bash
cd /var/www
# git clone <your-repo-url> whatsquery
cd whatsquery
```

Install dependencies:
```bash
npm install
```

Configure Environment:
```bash
cp .env.production.example .env
nano .env
# Fill in: DATABASE_URL, NEXTAUTH_SECRET, SUPER_ADMIN_EMAILS, etc.
```

Prepare Database & Build:
```bash
npx prisma migrate deploy
npx prisma generate
npm run seed:prod
npm run build
```

---

## 4. Process Management (PM2)

Install and start PM2:
```bash
sudo npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup
# Copy and run the command generated by pm2 startup
```

---

## 5. Nginx Reverse Proxy

Create Nginx configuration:
```bash
sudo nano /etc/nginx/sites-available/whatsquery
```

Paste this config (Replace `yourdomain.com`):
```nginx
server {
    listen 80;
    server_name yourdomain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Enable site and restart Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/whatsquery /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

---

## 6. SSL with Certbot

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com
```

---

## 7. Post-Deployment Checklist

- [ ] **Database**: Verify connection with `pm2 logs`.
- [ ] **Migrations**: Ensure `npx prisma migrate status` shows up to date.
- [ ] **Seeding**: Log in with `admin@whatsquery.com` using the current `SUPER_ADMIN_BOOTSTRAP_PASSWORD`, then rotate it immediately.
- [ ] **Admin**: Verify `/wq-command-center` is accessible.
- [ ] **Tenant**: Create a test business and verify onboarding flow.
- [ ] **Billing**: Select a package and verify the "Payment Pending" screen.
- [ ] **Invoicing**: Create a sale and verify invoice PDF generation.
- [ ] **Security**: Ensure `.env` is not world-readable (`chmod 600 .env`).
