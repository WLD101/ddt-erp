# WhatsQuery Voice - Client Onboarding Checklist

This checklist is designed to help local business clients (e.g. restaurants, salons, clinics in Pakistan) set up their WhatsQuery Voice AI Receptionist successfully.

## 1. Initial Setup
- [ ] Log in to the WhatsQuery Voice Tenant Dashboard.
- [ ] Navigate to **Settings > Business Identity**.
- [ ] Fill out the **Business Name**, **Industry**, and **Primary Language** (e.g., English, Urdu, Roman Urdu).
- [ ] Set your **Opening Hours**. The AI will use this to tell callers if you are open or closed.
- [ ] Provide a **Fallback Contact Method** (phone number or email) for human handoffs.

## 2. Receptionist Persona
- [ ] Go to **Training > Receptionist Persona**.
- [ ] Name your AI Receptionist.
- [ ] Choose the Tone (e.g., Professional, Friendly).
- [ ] Write a custom **Greeting Message** (e.g., "Assalam-o-Alaikum, thanks for calling XYZ Cafe. I'm the AI receptionist. How can I help you today?").
- [ ] Write a custom **Closing Message**.

## 3. Services & Menu
- [ ] Go to **Knowledge Base > Services / Menu**.
- [ ] Add all primary services or menu items.
- [ ] For restaurants, specify if Dine-In, Takeaway, and Delivery are available for each item.
- [ ] Add prices or price ranges if you want the AI to answer pricing questions.

## 4. FAQs (Frequently Asked Questions)
- [ ] Go to **Knowledge Base > FAQs**.
- [ ] Add common questions (e.g., "Do you have parking?", "Where are you located?").
- [ ] Provide clear, concise answers. The AI will read these verbatim or summarize them naturally.

## 5. Booking & Order Rules
- [ ] Go to **Training > Booking Rules**.
- [ ] If you take appointments or reservations, enable **Accepts Bookings**.
- [ ] Select required fields to capture (e.g., Name, Phone, Date, Time, Party Size).
- [ ] Go to **Training > Order Rules**.
- [ ] If you accept takeaway/delivery requests, enable **Accepts Order Requests**.
- [ ] Select required fields to capture.
- *Note: All bookings and orders are captured as "Requests" for staff to manually confirm.*

## 6. Sync to Telephony
- [ ] Go to **Integrations > Vapi Assistant Setup**.
- [ ] Click the **"Sync to Vapi"** button.
- [ ] Wait for the success confirmation. Your AI prompt and tools are now deployed to the telephony engine!

## 7. Go Live
- [ ] You will receive a dedicated phone number from WhatsQuery.
- [ ] Set up call forwarding from your main business line to the WhatsQuery Voice number.
- [ ] Call the number to verify the AI receptionist answers and follows your instructions!
