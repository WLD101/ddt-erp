# WhatsQuery Integration Provider Guide

This guide is intentionally limited to rollout planning for now.

Planned provider groups:

- Google
- Microsoft
- CRM providers
- Messaging providers
- Payments
- Webhooks / REST / automation

Before adding a provider:

1. attach it to capability-driven recommendations
2. define provider actions and scopes
3. define allowed industries / operational models
4. define voice action gating
5. add tenant-isolation tests
