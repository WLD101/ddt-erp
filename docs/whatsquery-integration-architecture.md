# WhatsQuery Integration Architecture

Current status: planning and capability groundwork only.

Current implemented integration surface is still mostly:

- sales-channel connections
- voice provider connections

The new profile layer is the prerequisite for a broader marketplace because it provides:

- profile-aware recommendations
- operational-model awareness
- capability-aware voice gating

Not yet implemented in this change:

- shared OAuth broker
- provider registry for Google/Microsoft/CRM
- shared connection wizard
- resource selectors
- approval framework for provider actions
